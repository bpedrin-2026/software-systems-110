Section 1: HTML Syntax Demonstration

HTML (HyperText Markup Language) is used to structure the content of a webpage. HTML uses elements, tags, and attributes to tell the browser what each piece of content is.

Basic HTML Document

Every HTML page needs a basic document structure: 

<!DOCTYPE html>
<html>
<head>
    <title>My Webpage</title>
</head>
<body>

    Your webpage content goes here.

</body>
</html>

The <html> element contains the entire webpage. The <head> contains information about the page, while the <body> contains the content displayed on the webpage.

HTML Elements

Most HTML elements have an opening tag and a closing tag. The content goes between the two tags.

Example: <p>This is a paragraph.</p>

Some elements do not need a closing tag. For example: <br>

Headings: <h1>–<h6>

Headings organize the content of a webpage. <h1> is the most important heading, while <h6> is the least important.

Paragraphs: <p>

Paragraph elements are used for normal blocks of text.

Example: <p>This is a paragraph.</p>

Line Breaks: <br>

The <br> element creates a line break without starting a new paragraph.

Example: Hello<br>World

Hello
World

Links: <a>

The <a> element creates a link. The href attribute tells the browser where the link should go.

Example: <a href="https://www.example.com">Visit Example</a>

Visit Example

Images: <img>

The <img> element displays an image. The src attribute tells the browser where the image is located, and the alt attribute provides a text description of the image.

Example: <img src="image.jpg" alt="Description of image">

Containers: <div>

A <div> is used to group related content together. Divs are commonly used to organize sections of a webpage.

Example: 

<div>
    <h2>About Me</h2>
    <p>This content is grouped together.</p>
</div>

Text Input

An input element can allow a user to enter text.

Example: <input type="text">

Checkbox Input

A checkbox allows a user to select or unselect an option.

Example: <input type="checkbox">

Example checkbox

Buttons: <button>

The <button> element creates a clickable button. A button does not need to do anything yet. Later, JavaScript can be used to make a button perform an action.

Example: <button>Click Me</button>

HTML and Markup Language Syntax

HTML stands for HyperText Markup Language, and is the backbone of every website. It lays out the basic structure of the website, including the text, images, and user interactive elements.

Main Features of an HTML Document

  1. <html> - This is the open declaration of the document, and is written <!DOCTYPE html>.
    It tells the browser that the document is going to run on the HTML protocol.
  2. <head> - This is the section that stores information that will not be displayed as main content of the site
  3. <body> - This is where the main content for the user is written and displayed
  4. <footer> -This is the information at the bottom of the website

Tags

Each section of an html document is broken up into compartments with the use of opening and closing tags.

These tags define a specific, referenceable division in a markup document.
These divisions are used in CSS, a styling language, to customize the asthetic of your website.
Some tags do not require a closing tag because they are simply actions that don't require a future CSS reference.
